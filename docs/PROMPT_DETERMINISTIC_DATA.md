# Спецификация детерминированных данных пользователя

В данном документе описаны фиксированные параметры пользователя, которые вычисляются ровно один раз при первом запуске приложения (или при изменении профиля) и сохраняются в локальную базу данных (например, Isar/SQLite). Эти данные формируют постоянный "кармический" базис для ИИ.

## 1. Структура постоянных параметров

### 1.1. Имя пользователя (`user_name`)
*   **Тип данных:** `String`
*   **Логика:** Текстовое имя, введенное пользователем.
*   **Назначение:** Используется ИИ для прямой персонализации обращения в тексте (например, "Дмитрий, твои огненные силы...").

### 1.2. Классический Знак Зодиака (`zodiac_sign`)
*   **Тип данных:** `String`
*   **Логика:** Вычисляется на основе дня и месяца рождения пользователя.
*   **Диапазон значений:** Овен, Телец, Близнецы, Рак, Лев, Дева, Весы, Скорпион, Стрелец, Козерог, Водолей, Рыбы.

### 1.3. Астрологическая стихия (`astrological_element`)
*   **Тип данных:** `String`
*   **Логика:** Жестко привязана к знаку зодиака.
    *   *Огонь:* Овен, Лев, Стрелец.
    *   *Земля:* Телец, Дева, Козерог.
    *   *Воздух:* Близнецы, Весы, Водолей.
    *   *Вода:* Рак, Скорпион, Рыбы.
*   **Назначение:** Задает базовую метафорику для ИИ (огонь — страсть/напор, земля — стабильность/опора и т.д.).

### 1.4. Планета-покровитель (`ruling_planet`)
*   **Тип данных:** `String`
*   **Логика:** Главное небесное тело, управляющее знаком зодиака.
*   **Маппинг знаков:** Марс (Овен), Венера (Телец, Весы), Меркурий (Близнецы, Дева), Луна (Рак), Солнце (Лев), Плутон (Скорпион), Юпитер (Стрелец), Сатурн (Козерог), Уран (Водолей), Нептун (Рыбы).

### 1.5. Число судьбы / Нумерология (`destiny_number`)
*   **Тип данных:** `Int` (значение от 1 до 9)
*   **Логика:** Свертывание полной даты рождения (ДД.ММ.ГГГГ) путем последовательного сложения всех цифр до получения одного числа.
*   **Пример расчета:** 25.11.1995 -> 2+5+1+1+1+9+9+5 = 33 -> 3+3 = 6.

### 1.6. Тотемный год по Восточному календарю (`chinese_totem`)
*   **Тип данных:** `String`
*   **Логика:** Вычисляется на основе года рождения.
*   **Диапазон значений:** Крыса, Бык, Тигр, Кролик, Дракон, Змея, Лошадь, Коза, Обезьяна, Петух, Собака, Свинья.

### 1.7. Возрастная группа (`age_group`)
*   **Тип данных:** `String`
*   **Логика:** Вычисляется на основе текущего года минус год рождения.
    *   *Меньше 18:* "Подростковый тон общения"
    *   *18 - 30:* "Молодой, амбициозный тон общения"
    *   *30+:* "Зрелый, глубокий, психологический тон общения"

## 2. Формат хранения и передачи (JSON)

```json
{
  "user_name": "Дмитрий",
  "zodiac_sign": "Лев",
  "astrological_element": "Стихия Огня",
  "ruling_planet": "Солнце",
  "destiny_number": 6,
  "chinese_totem": "Год Кабана",
  "age_group": "Зрелый (30+)"
}
```
