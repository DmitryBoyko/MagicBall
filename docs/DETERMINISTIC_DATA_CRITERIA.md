# Критерии детерминированных (фиксированных) данных профиля

В этом документе описаны параметры, которые привязаны к личности пользователя. Они рассчитываются один раз на основе анкетных данных при первом запуске приложения и не меняются при последующих тапах по шару.

## 1. Перечень постоянных параметров

### 1.1. Имя пользователя (`user_name`)
*   **Тип:** `String`
*   **Критерий применения:** Используется для точечной персонализации (прямого или завуалированного упоминания имени внутри текста).

### 1.2. Классический Знак Зодиака (`zodiac_sign`)
*   **Тип:** `String`
*   **Критерий применения:** Определяет принадлежность пользователя к астрологическому знаку (Овен, Лев, Скорпион и т.д.).

### 1.3. Астрологическая стихия (`astrological_element`)
*   **Тип:** `String`
*   **Критерий применения:** Напрямую определяет базовый смысловой пласт метафор для ИИ. Всего 4 стихии: Огонь (напор, страсть), Земля (стабильность, опора), Воздух (перемены, интеллект), Вода (интуиция, эмоции).

### 1.4. Планета-покровитель (`ruling_planet`)
*   **Тип:** `String`
*   **Критерий применения:** Небесное тело знака (Солнце, Марс, Плутон и др.), усиливающее мистический контекст в глазах игрока.

### 1.5. Число судьбы / Нумерология (`destiny_number`)
*   **Тип:** `Int` (от 1 до 9)
*   **Критерий применения:** Нумерологический код, полученный путем сложения всех цифр даты рождения до единичного остатка. Служит для калибровки вектора судьбы в промпте.

### 1.6. Тотемный год по Восточному календарю (`chinese_totem`)
*   **Тип:** `String`
*   **Критерий применения:** Животное-тотем года рождения (Год Дракона, Год Кабана и т.д.) для расширения базы ассоциаций ИИ.

### 1.7. Возрастной ценз для тональности (`age_group`)
*   **Тип:** `String`
*   **Критерий применения:** Вычисляется из возраста для корректировки психологической глубины текста (например, "Зрелый тон 30+" требует более глубокой психотерапевтической подачи, а "Подростковый тон" исключает сложные философские концепты).
