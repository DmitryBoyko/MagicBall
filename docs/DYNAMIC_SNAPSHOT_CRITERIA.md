# Критерии динамических (сиюминутных) данных контекста

Этот документ описывает переменные параметры среды и смартфона, которые собираются «на лету» строго в миллисекунду тапа по шару. Они отвечают за уникальность гадания «здесь и сейчас».

## 1. Системные и географические маркеры
*   **Точное время и день недели (`exact_time`):** Системное время (например, "Пятница, 23:15"). Помогает ИИ обыгрывать контекст конца недели или ночного времени.
*   **Время суток (`time_of_day`):** Текстовый маппинг часов (Утро, Разгар дня, Вечерняя тишина, Час ведьм) для задания общей атмосферы текста.
*   **Сезон / Время года (`current_season`):** Название текущего сезона для использования природных метафор увядания (осень) или пробуждения (весна).
*   **Тип локации (`geo_location_type`):** Населённый пункт из Nominatim плюс тип местности из федерального округа / координат (например, «Кемерово, Кемеровская область — сибирский город», «Сочи, Краснодарский край — южный приморский город»).
*   **Погода (`weather_state`):** Open-Meteo / met.no по координатам (без ключа), таймаут 3 с, кэш 30 мин. Дождь, метель, туман, зной — привязка окружения к настроению текста. Нет данных — поле не отправляется.

## 2. Аппаратная аура устройства
*   **Заряд батареи (`battery_aura`):** Переводится в метафору личных энергетических ресурсов пользователя (Низкий заряд = истощение, Полный заряд = избыток сил).
*   **Статус питания (`power_state`):** Подключена ли зарядка. Интерпретируется как наличие внешней поддержки (кабель подключен) или опора только на себя (кабель отключен).

## 3. Данные компьютерного зрения (Анализ последнего фото через MobileNetV2)
*   **Мистический архетип кадра (`photo_mystic_tag`):** Смысловой класс, полученный после обработки тега нейросети через маппер (например, "Стальное Отсечение", "Архетип Верного Спутника").
*   **Палитра цвета (`color_palette`):** Названия преобладающих гекс-оттенков на фотографии (например, "Бирюзовый, неоновый алый, глубокий черный").
*   **Экспозиция кадра (`luminance_vibe`):** Световой тон. Яркий кадр интерпретируется как ясность мыслей, темный — как скрытые тайны и неопределенность.

## 4. Внутриигровая энтропия (Модификаторы фатума)
*   **Слово-якорь дня (`entropy_anchor`):** Случайный архетипичный предмет или явление из базы данных приложения (1 из 60), заставляющий ИИ строить уникальный сюжет вокруг этого слова.
*   **Настроение Хрустального Шара (`ball_mood`):** Случайный выбор эмоционального фильтра (1 — Мягкая поддержка, 2 — Строгий реализм, 3 — Туманная загадка).
*   **Давление внешнего мира (`world_pressure`):** Случайный вектор состояния социума вокруг игрока (1 — Стагнация и тишина, 2 — Шум и суета, 3 — Скрытая угроза).
