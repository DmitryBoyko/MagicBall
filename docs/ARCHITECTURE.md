# Архитектура «Волшебный шар: гадание»

Один экран Godot 4.7 Mono (C# / .NET 8), портрет 720×1600. Клиент собирает контекст, обрабатывает фото через MobileNetV2 и вызывает GigaChat по тому же контракту, что TrueTaro.

## Слои

```
Ui (MainScene)
 ├─ ProfileModal / InterpretationSheet / AdOverlay / VortexField
 ├─ ContextManager          ← имя, зодиак, батарея, пульс вопрошания, якоря, фото-тег
 ├─ Vision                  ← ImagePreprocessor → PhotoSampler → OnnxInferenceEngine → InferenceWorker
 └─ AiGateway               ← FIFO 5с → GigaChatClient → extract_summary
                                 ↓ сбой / очередь полна
                            SemanticCache (порог 0.82) → MeaningBank.synthesize (156)
```

| Класс | Роль |
|---|---|
| `GameRoot` | Autoload: прогрев ONNX, профиль, настройки, музыка |
| `ProfileStore` | `user://user_profile.json` |
| `InquiryPulseStore` | `user://oracle_pulse.json` — тапы за последние N суток (по умолчанию 3), ротация устаревших дней |
| `InquiryPulseMeter` | Плотность + вспышки + свежесть → `inquiry_pulse_aura` |
| `AstroCalculator` | Знак, стихия, планета, число судьбы, тотем, возраст |
| `ContextManager` | Склейка детерминированных + динамических + хаос-модификаторов |
| `ImagePreprocessor` | Последнее фото / тест → 224×224 RGB8 ImageNet NCHW (150528 float) |
| `OnnxInferenceEngine` | Синглтон `InferenceSession`, NNAPI→CPU, защита от `DllNotFoundException` |
| `PhotoSampler` | Последние 3–10 фото по одному → сводка архетипа/палитры/света |
| `MysticTagConverter` | ImageNet → русский архетип |
| `OracleProxyClient` | `POST /api/v1/oracle` — ключ Sber только на сервере |
| `AiGateway` | прокси → локальный synthesize, `osiris_present` |
| `SummaryExtractor` | Тело → `interpretation`, хвост после `[[ИТОГ]]` → `summary` |
| `VortexField` | 2600 частиц, 3 центра, 5 рукавов, фазы 0.08 / 0.22 / ≥2.4 / 0.95 с |

## Поток гадания

Кнопки «Спросить» нет. Под фразой внутреннего настроя постоянно показана инструкция
«и прикоснись три раза к шару-оракулу».

### Ритуал касаний

1. Считаются только нажатия внутри круглой области шара. Один физический тап даёт одно событие `ScreenTouch`; эмуляция touch→mouse отключена.
2. Успех — три касания, оба интервала (1→2 и 2→3) находятся в диапазоне **0,5–2,2 с**.
3. Одиночное касание ничего не запускает: нет ни рекламы, ни запроса.
4. Если второе касание пришло раньше 0,5 с или позже 2,2 с, ритуал провален.
5. После корректной пары отсутствие третьего касания дольше 2,2 с также проваливает ритуал.
6. При провале шар тускнеет и светится как при серверном сбое, первая подсказка заменяется случайной отказной фразой из `OracleUnreadyCatalog`, показывается обязательная rewarded-реклама. Запрос к прокси/GigaChat не выполняется.
7. После рекламы можно начать новую тройку. Возврат Android-приложения в фокус снимает зависшую рекламную блокировку, если плагин потерял callback закрытия.

### Успешная тройка

1. Касания блокируются до полного завершения гадания и закрытия модалки с ответом.
2. Запускается полноэкранный вихрь. Параллельно последние N фото обрабатываются по одному (декод на главном потоке, MobileNet в фоне), остальные доступные сигналы собираются в контекст.
3. Шар входит в вихрь, HTTP-запрос к GigaChat ставится в FIFO.
4. Удержание вихря длится не короче 2,4 с, даже если ответ уже получен; спад — 0,95 с.
5. После готового LLM-ответа показывается обязательная rewarded-реклама. Если награда не подтверждена, вместо ответа открывается туман.
6. После подтверждённой рекламы сразу открывается модалка толкования. Новые касания разрешаются только после её закрытия.

## Данные

- Профиль, настройки и пульс вопрошания — JSON в `user://` (timestamps шара на сервер не уходят).
- Секреты GigaChat — `res://config/api.json` (как TrueTaro `.env`: Basic-ключ, Client ID, scope).
- Модель — `res://models/mobilenetv2-7.onnx`, при старте копируется в `user://models/` (реальный путь для native ORT).
- Якоря — `res://data/semantic_anchors.json` (60 позиций).
